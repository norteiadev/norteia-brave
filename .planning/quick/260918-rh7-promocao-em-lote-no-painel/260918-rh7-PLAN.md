<objective>
Add batch promotion of DLQ atrativos to Mar: one endpoint that dry-runs a filtered
candidate set (UF + score + description + recency), then a confirmed real run that
promotes each candidate independently (per-record commit/rollback isolation, not a
single all-or-nothing transaction) and dispatches the existing async Mar push per
promoted record. Add a "Promover em lote" control to the Painel that runs
dry-run -> confirm -> real call scoped to the board's current UF filter.

Purpose: TA-lane atrativos cap at score 72.5 < threshold_mar 80, so EVERY one of the
~6k promotable DLQ atrativos (out of ~10k whole-Brazil) needs a steward's manual +15
validacao_humana promote. The Painel has no multi-select today — this turns
thousands of one-card clicks into a handful of batch confirmations, without
lowering the threshold and without auto-promoting anything without a human action.

Output: `POST /api/v1/atrativos/promote-bulk` (dry_run + real), a "Promover em lote"
Painel control, offline pytest + vitest coverage.

| Engine LIGADO state -> mutation gate | The bulk endpoint must respect the SAME `require_editing_unlocked` 423 gate as every other card mutation — a missing dependency here would let a steward bulk-promote records out from under an in-flight sweep. |
